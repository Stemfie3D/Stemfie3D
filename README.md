# STEMFIE

**The free, open-source construction set you print at home.**

STEMFIE is a 3D-printable construction system for makers, families, and schools. Every part follows one open standard, so anything you build fits anything anyone else builds.

- **Download parts and kits:** https://get.stemfie.org
- **Lessons and courses:** https://stemfie.org/learn/
- **Website:** https://stemfie.org/?utm_source=github&utm_medium=readme

## What lives here

Source code and specifications: the publishing tools, the STEMFIE Standard, and future software. Printable files are not kept in Git — they are published on get.stemfie.org, which is the canonical source.
